TODO: 이 시스템은 검색 증강 생성(RAG)을 적용하여 시맨틱 검색과 언어 모델 추론을 연결합니다. 문서는 전처리되고, 겹치는 구절로 청크화되며, 벡터 데이터베이스에 임베딩됩니다. 쿼리 시 의미적으로 관련된 구절이 검색 및 랭킹되어 답변 생성을 위한 그라운딩된 컨텍스트로 언어 모델에 전달됩니다. 모든 응답에 출처 정보가 포함됩니다.

TODO: 아키텍처 / 워크플로우

수집 → 전처리 → 임베딩 → 벡터 DB → 검색 → 프롬프트 구성 → 응답 생성 → REST API

TODO: 문서는 여러 형식에서 수집되어 정리되고, 구성 가능한 크기와 스트라이드로 겹치는 청크로 분할됩니다. 각 청크는 임베딩되어 벡터 인덱스에 저장됩니다. 사용자 쿼리는 상위 k개의 관련 구절을 반환하는 시맨틱 검색을 트리거하며, 이는 토큰 예산 관리와 함께 구조화된 프롬프트로 조합됩니다. 언어 모델이 답변을 생성하고 FastAPI 엔드포인트를 통해 스트리밍 옵션과 함께 반환됩니다.
